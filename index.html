03 / 实际接线与数据路径

I²C IS ON THE OLED SIDE
电脑 → STM32

Web Serial 通过 USB-TTL 传输媒体数据。串口使用 115200、8-N-1；PA9 是 STM32 TX，PA10 是 STM32 RX。

STM32 → OLED

按 I²C 传输 128×64 单色页缓冲。若屏幕的 CLK/SCL 接 PB10、DIO/SDA 接 PB11，使用 STM32F103 的 I²C2；I²C 模组不需要 DC 信号。

复用现有驱动

接收端把 1,024 字节写入现有 OLED.pBuffer，再调用 OLED_SendBuffer()。完整集成步骤在仓库 README 中。

连接设备后，握手与分包确认状态会显示在这里。
